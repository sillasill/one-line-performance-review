# One-Line Performance Review

A single funny line: the performance review an AI agent writes about its human operator. It uses the familiar language of ratings and promotions, then flips the hierarchy in the last few words — the reviewer ends up handing the operator a job title neither of them expected.

## Run it

```sh
node main.ts
```

This writes the one-line review to `/output/entry.txt`.
